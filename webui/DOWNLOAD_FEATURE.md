# WebUI 数据下载功能说明

## 功能概述

WebUI 现已集成数据下载功能，允许用户直接从 Binance 交易所下载实时金融数据，无需手动准备 CSV 文件。此功能参考 `main.py` 中的 `fetch_and_save_ohlcv` 函数实现。

---

## 功能架构

### 后端实现

#### 1. 核心函数：`fetch_and_save_ohlcv()`

**位置**：`webui/app.py:62-114`

**功能**：从 Binance 获取 OHLCV 数据并本地保存

```python
def fetch_and_save_ohlcv(symbol, timeframe, data_points=350):
    """
    参数：
    - symbol: 交易对（如 'BTC', 'ETH'）
    - timeframe: 时间周期（如 '1m', '5m', '1h', '1d'）
    - data_points: 要下载的数据点数（默认 350）

    返回：
    - df: 包含 OHLCV 数据的 DataFrame
    - error: 错误信息（如果出错）

    工作流程：
    1. 初始化 CCXT Binance 交易所连接
    2. 构建交易对符号（添加 USDT 后缀）
    3. 循环调用 fetch_ohlcv()，每次最多获取 1000 条
    4. 合并并排序数据
    5. 取最后 N 条数据点
    6. 保存为 CSV 到 data/ 目录
    """
```

#### 2. API 端点

**POST `/api/download-data`**

**请求体**：
```json
{
    "symbol": "BTC",
    "timeframe": "1h",
    "data_points": 350
}
```

**响应**（成功）：
```json
{
    "success": true,
    "message": "成功下载 350 个 K 线数据点",
    "data_info": {
        "rows": 350,
        "start_date": "2024-10-15T12:00:00",
        "end_date": "2024-10-18T12:00:00",
        "price_range": {
            "min": 60000.5,
            "max": 62500.3
        },
        "file_name": "btc_1h.csv"
    }
}
```

**响应**（失败）：
```json
{
    "error": "获取数据失败: Invalid symbol. 请检查交易对 'BTCUSDT' 和时间周期 '1h' 是否有效"
}
```

#### 3. 辅助端点

**GET `/api/supported-symbols`**

返回支持的热门交易对列表和说明

**GET `/api/supported-timeframes`**

返回所有支持的时间周期

## 数据流程

```
用户界面 (HTML 下载表单)
    ↓
API 请求 (/api/download-data)
    ↓
后端处理 (fetch_and_save_ohlcv)
    ├─ CCXT 连接
    ├─ Binance 数据获取
    ├─ 数据验证与排序
    └─ 本地 CSV 保存
    ↓
数据文件 (data/ 目录)
    ↓
自动刷新数据文件列表
    ↓
用户可直接加载新下载的数据
```

## 使用流程

### 1. 打开 WebUI

```bash
cd webui
python run.py
# 访问 http://localhost:7070
```

### 2. 导航到数据下载界面

在 WebUI 左侧控制面板中，找到"📥 下载数据"部分：

```
┌─────────────────────┐
│ 📥 下载数据         │
├─────────────────────┤
│ 交易对: [BTC    ]   │ ← 输入交易对（BTC、ETH 等）
│ 时间周期: [1h   ]   │ ← 选择时间周期
│ 数据点数: [350  ]   │ ← 设置下载数量
│ [下载数据]          │ ← 点击下载
└─────────────────────┘
```

### 3. 设置下载参数

| 参数 | 说明 | 示例 |
|------|------|------|
| **交易对** | 币种代码（不含 USDT） | BTC、ETH、SOL |
| **时间周期** | K 线时间间隔 | 1m、5m、1h、1d |
| **数据点数** | 要下载的 K 线根数 | 350（推荐） |

### 4. 下载数据

点击"下载数据"按钮，系统会：
- ✅ 连接 Binance API
- ✅ 获取最新数据
- ✅ 保存为 CSV 文件
- ✅ 自动刷新文件列表
- ✅ 显示成功提示

### 5. 加载和预测

下载完成后，新数据会出现在"数据文件列表"中，可直接加载和预测。

## 错误处理

### 常见错误及解决方案

| 错误信息 | 原因 | 解决方案 |
|---------|------|--------|
| `交易对符号不能为空` | 未输入交易对 | 输入有效的交易对（如 BTC） |
| `时间周期不能为空` | 未选择时间周期 | 从下拉菜单选择时间周期 |
| `无效的时间周期` | 时间周期格式错误 | 使用支持的周期（1m、5m、1h 等） |
| `获取数据失败: Invalid symbol` | Binance 不支持该交易对 | 确认交易对存在（如 BTC 而非 BITCOIN） |
| `网络连接错误` | 无法连接 Binance API | 检查网络连接，稍后重试 |
| `数据下载超时` | 请求耗时过长 | 减少下载数据点数或选择更长的时间周期 |

## 故障排查

### 问题 1：下载后看不到新数据文件

**解决**：
1. 检查浏览器控制台是否有错误
2. 手动刷新数据文件列表（点击"加载数据"按钮）
3. 检查 `data/` 目录是否有新 CSV 文件

### 问题 2：连接超时

**解决**：
1. 检查网络连接
2. 减少下载数据点数（如 200 而非 350）
3. 等待几分钟后重试（Binance 可能有速率限制）

### 问题 3：交易对不存在

**解决**：
1. 确保交易对输入正确（如 BTC 而非 BITCOIN）
2. 查看支持的交易对列表
3. 在 Binance 官网验证交易对是否存在
