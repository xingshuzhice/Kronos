# 重复预测失败问题诊断

## 问题描述

**症状**：
- 第一次点击"开始预测" → ✅ 成功
- 第二次及以后点击"开始预测" → ❌ 400 BAD REQUEST 错误

**浏览器控制台错误**：
```
POST http://127.0.0.1:7070/api/predict 400 (BAD REQUEST)
❌ 预测失败: de {message: 'Request failed with status code 400', ...}
```

---

## 可能原因分析

### 原因 1: 时间滑块状态混乱（最可能）
**症状**：第一次预测后，时间滑块的位置被修改或重置

**解决**：
```javascript
// 检查浏览器控制台是否看到这样的日志：
🚀 开始预测，参数: {
  start_date: '2025-10-02T10:54',  // ← 第一次
  ...
}

🚀 开始预测，参数: {
  start_date: '2025-10-02T10:55',  // ← 第二次（时间改变了？）
  ...
}
```

### 原因 2: 后端状态被污染
**症状**：全局变量 `predictor`、`model`、`tokenizer` 被修改或释放

**可能的触发点**：
- 异常处理中的变量被重置
- 内存溢出导致模型被卸载
- 并发请求冲突

### 原因 3: 数据文件被锁定
**症状**：第一次读取后文件被锁定，第二次无法读取

### 原因 4: 时间范围验证失败
**症状**：第一次预测后，时间滑块的设置不再有效

---

## 快速诊断步骤

### 步骤 1: 查看浏览器控制台
打开 F12 → 控制台，第二次预测时的参数：

```javascript
// 查看这两行的区别
🚀 开始预测，参数: {...}  // 第一次
🚀 开始预测，参数: {...}  // 第二次

// 比较 start_date、file_path、lookback、pred_len
```

### 步骤 2: 查看后端日志
在运行 Flask 的终端，查看第二次预测请求的日志：

```
[检查] 准备执行预测...
[检查] 请求编号: XXXXX
[检查] predictor 对象有效: True
[执行] 开始 Kronos 模型预测...
[检查] 数据文件列: [...]
```

**如果看不到这些日志**，说明请求在早期阶段就失败了。

### 步骤 3: 查看具体错误
第二次预测时，观察终端中是否有这样的错误：

```
[错误] Kronos 模型预测失败: ...
[错误] 异常类型: ...
[堆栈跟踪]: ...
```

## 临时解决方案

### 方案 1: 每次预测前重新加载模型
```
1. 点击预测 → 成功 ✅
2. 点击"加载模型"（重新加载）
3. 点击预测 → 应该成功 ✅
```

### 方案 2: 刷新页面后再预测
```
1. 点击预测 → 成功 ✅
2. F5 刷新页面
3. 重新加载模型和数据
4. 点击预测 → 应该成功 ✅
```

### 方案 3: 不调整时间滑块
```
1. 加载数据后，不要动时间滑块
2. 直接点击预测
3. 第一次预测 → ✅
4. 第二次预测 → ✅（应该成功）

说明：使用默认时间范围（最新数据模式）
```

## 常见场景

### 场景 1: 时间滑块问题
**症状**：
```
第一次: start_date: '2025-10-01T10:00'  ✅
第二次: start_date: '2025-10-01T11:00'  ❌

错误信息: 数据不足
```

**原因**：时间滑块位置改变，导致选择的时间范围不足 520 行

**解决**：检查时间滑块是否被无意中拖动

### 场景 2: 内存问题
**症状**：
```
第一次: ✅ 成功
第二次: ❌ CUDA Out of Memory 或类似错误
```

**原因**：GPU/内存未正确释放

**解决**：
- 尝试使用 CPU 模式
- 减小 sample_count
- 使用更小的模型（kronos-mini）

### 场景 3: 数据并发访问
**症状**：
```
第一次: ✅ 成功
第二次: ❌ I/O 错误或文件锁定错误
```

**原因**：文件被锁定，无法再次读取

**解决**：稍等片刻后重试
