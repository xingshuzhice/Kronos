## ✅ 测试 1：按钮启用检查

### 步骤
1. 打开浏览器，访问 `http://localhost:7070`
2. 打开开发者工具（F12）→ 控制台标签

### 预期结果
- ❌ **初始状态**："开始预测"按钮应为灰色（禁用）
  - 控制台显示：`⚠️ 预测按钮禁用（需要加载模型和数据）`

- ✅ **加载模型后**：按钮应变蓝色（启用）
  - 选择模型 → 点击"加载模型"
  - 按钮变可点击
  - 控制台显示：`✅ 预测按钮已启用（模型和数据已加载）`

- ✅ **加载数据后**：按钮保持启用
  - 选择数据文件 → 点击"加载数据"
  - 按钮仍然可点击
  - 控制台显示：`✅ 预测按钮已启用（模型和数据已加载）`

## ✅ 测试 6：预测执行 - 错误处理

### 错误场景 1：未加载模型
```
1. 加载数据 (不加载模型)
2. 点击"开始预测"
```
**预期**：
- ❌ 按钮应被禁用（无法点击）
- 或显示错误：`❌ 请先加载模型`

### 错误场景 2：未加载数据
```
1. 加载模型 (不加载数据)
2. 点击"开始预测"
```
**预期**：
- ❌ 按钮应被禁用（无法点击）
- 或显示错误：`❌ 请先加载数据文件`

### 错误场景 3：模型加载失败模拟
```
1. 选择不存在的模型
2. 尝试加载
```
**预期**：
- 显示错误：`模型加载失败: ...`
- 按钮保持禁用

### 错误场景 4：网络超时（需要手动模拟）
```
1. 断开网络或加长网络延迟
2. 尝试预测
```
**预期**：
- 显示错误：`网络超时或服务器无响应，请稍后重试`
- 浏览器控制台显示：`请求已发送但无响应`

## 🆘 问题排查

如果某个测试失败，按以下步骤排查：

### 问题：按钮始终禁用
```
原因可能：
1. 模型未加载 → 检查浏览器控制台错误
2. 数据未加载 → 确认数据文件存在
3. 前端代码未更新 → 清除浏览器缓存 (Ctrl+Shift+Delete)
```

### 问题：预测无反应
```
原因可能：
1. 模型加载失败 → 检查后端日志
2. 数据不兼容 → 验证数据格式
3. 网络问题 → 检查浏览器控制台网络标签
```

### 问题：看不到后端日志
```
原因可能：
1. Flask 未运行在前台 → 重新启动应用
2. 日志输出被重定向 → 检查标准输出
```
